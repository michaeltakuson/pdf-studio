# 画面の操作テスト

実際のブラウザを、実際のマウス・キーボード操作で動かして確かめるためのスクリプトです
（Playwright の `page` を受け取る関数）。プログラムからイベントを直接送るテストでは、
「マーカーが実マウスでは効かない」といった不具合を見逃した経緯があるため、こちらを使います。

| ファイル | 確かめること |
|---|---|
| `editing.js` | 文字の入力・再編集・コピー＆ペースト・矢印キー・幅の変更・線の端点・右クリック |
| `study-tools.js` | 修正テープ・暗記シート・切り抜きコピー・しおり自動作成・トリミング |
| `documents.js` | マーカーの色・元に戻す・定型文・スライドショー・ページ操作・墨消し・パスワード付きPDF |
| `arrange-touch-spread.js` | 整列・指でのドラッグ・見開き |
| `files-and-saving.js` | ドロップ・画像の貼り付け・ファイルへの保存・自動保存・印刷・書き出し |
| `edit-while-loading.js` | エンジンの準備中に書き込み、準備完了後に引き継がれること |

## 使い方

1. `webapp/` を配信する（`python -m http.server 8765 --bind 127.0.0.1`）。サーバーを立てない場合は、
   Playwright の `page.route()` で `http://127.0.0.1:8765/**` をディスク上の `webapp/` から返してもよい
2. スクリプト冒頭の `S`（作業フォルダ）を書き換え、そこに `tests/sample.pdf` などを置く
3. Playwright から関数を実行し、返ってきた値を確認する（`errors` が空であること）

注意:
- ブラウザはモジュールを強くキャッシュします。直したのに変わらないときは URL に `?t=<時刻>` を付けるか、
  サービスワーカーの登録を解除してください
- 保存していない変更があると、ページを離れるときに確認ダイアログが出ます（スクリプトは自動で承諾します）
