# PDF Studio

ブラウザだけで動く、無料のPDF編集アプリです。インストール不要、サーバーなし。
開いたPDFは**その端末のブラウザの中だけで処理され、どこにも送信されません。**

**使う → https://michaeltakuson.github.io/pdf-studio/**

## できること

画面はワープロソフトと同じ**タブ付きリボン**です（ファイル／ホーム／挿入／描画／ページ／校閲／表示／ツール）。

**文字を書き込む**
- 「テキスト追加」→ クリックした場所にそのまま入力。枠は文字に合わせて自動で伸び縮みする
- 書いた文字は**クリックするだけでその場で再編集**。枠をつかめば移動、端のハンドルで幅を変えると折り返す
- フォントは5種類（ゴシック・明朝・丸ゴシック・教科書体・手書き風）。**PDFに埋め込まれる**ので、どのソフトで開いても同じ日本語の字形になる
- 日本語入力（かな漢字変換）中のキーは変換にだけ効く。Enterで確定してもダイアログが閉じたり送信されたりしない

**元の文章を直す**
- 「本文を編集」→ PDFに元からある行をクリックして書き換え
- 検索して置換

**マーカー・コメント**
- 文字をなぞって選ぶと、その場にマーカー／下線／取り消し線／波線のボタンが出る
- 付箋、引き出し線、図形（直線・矢印・四角・円・多角形・折れ線・雲形）、手書きペン・蛍光ペン（筆圧対応）
- コメント一覧（絞り込み・返信・承認ステータス）。返信とステータスは規格どおりに保存され、Acrobat などのコメント欄にも同じ会話が出る

**申込書・契約書に記入する**
- チェック ✓・バツ・丸をクリックで置く
- **はんこ作成**（認印・日付印・角印）、**署名**（手書き・名前入力・画像。次回のために保存できる）
- 画像の挿入（ファイル、ドラッグ＆ドロップ、Ctrl+V で貼り付け）、今日の日付、スタンプ
- **定型文**: 氏名・住所・電話番号などを登録しておき、1クリックで入れる
- PDFの入力欄（フォーム）は**ページ上の青い枠をクリックしてそのまま入力**。データの書き出し・読み込み・複数回答の集計も
- **修正テープ**: 囲んだところを紙の色（スキャンの地色にも自動で合わせる）で隠し、上から書き直す

**ページを整理する**
- 左のページ一覧でドラッグして並べ替え、Ctrl / Shift で複数選択、右クリックで操作
- 回転・削除・複製・白紙の挿入・別PDFの結合（複数可）・抜き出し・分割
- **ノート用の余白を足す**（スライドの横にメモ欄）、**配布資料**（2/4/6/8/9ページを1枚に）
- ページ番号・ヘッダー／フッター・透かし・通し番号

**勉強・調べもの**
- マーカーは選んだその場で**4色を1クリックで使い分け**
- **暗記シート**: マーカーを引いたところを隠し、クリックで答え合わせ（赤シートの要領）
- **切り抜きコピー**: 囲んだ範囲を画像としてコピー。図や表をレポート・ノートアプリにそのまま貼れる
- 文字を選ぶと、その場から**翻訳**・Web検索（押したときだけ、選んだ文字を Google に送って新しいタブで開く）
- **しおり（目次）を見出しから自動作成**。スライドは各ページのタイトルから
- トリミング（余白を切って大きく表示）、ノート用の余白追加、配布資料（複数ページを1枚に）

**スキャンした文書**
- **文字認識（OCR）**: 画像の文字を読み取り、検索・選択・マーカーができるようにする（日本語・英語。ブラウザ内で実行）
- 範囲マーカー（文字情報のないページ用）

**消す・守る**
- 墨消し: 指定 → 適用で、下の文字と画像をファイルから実際に削除。検索して一括指定も可
- 隠れた情報（メタデータ・埋め込みファイルなど）の削除
- パスワード保護（AES-256・権限指定）、パスワード付きPDFを開く

**出す**
- 上書き保存（Ctrl+S、元のファイルへ直接）／名前を付けて保存／印刷
- ページを画像に（PNG/JPEG）、文字だけをテキストに、ファイルを軽くする（画像の縮小）
- 書き込みの一覧をPDF・CSV・Markdown・XFDFに。画像からPDFを作る、白紙から作る

**そのほか**
- **アプリとしてインストールできる**（ブラウザのアドレスバーの「インストール」）。一度開けばオフラインでも動き、PDFの「プログラムから開く」にも出る
- **開いた瞬間に読める**: 編集機能の準備（初回30秒〜1分）を待たずにPDFが表示され、準備ができると自動で編集可能になる
- **最近使ったファイル**を最初の画面から1クリックで開く。**自動保存**（オンにすると、元のファイルへ自動で上書き）
- **スライドショー**（F5）: 全画面で1ページずつ。マウスを押している間はレーザーポインター
- 元に戻す／やり直し。**ページの削除や墨消しの適用も Ctrl+Z で戻せる**
- 保存し忘れてタブを閉じても、次に同じファイルを開いたときに**書き込みを復元**できる
- 検索（空白を無視した照合つき。OCRした日本語も見つかる）、検索結果すべてにマーカー
- 文書内のリンク（目次・URL）、しおりの追加・改名・削除、前回読んでいたページから再開
- 読み上げ、ダークモード、ページの白黒反転、計測・数量拾い、2つの版の比較、アクセシビリティ点検

## しくみ

```
webapp/
  index.html, css/, js/      画面（素のJavaScript、ビルド不要）
  js/engine-worker.js        PDFエンジンを動かす Web Worker
  sw.js, manifest.webmanifest  オフライン動作とアプリとしてのインストール
  py/pdfstudio/              PDFの読み書き（Python。PyMuPDF を使う）
  vendor/pdfjs/              ページの描画（pdf.js）
  vendor/pymupdf-wasm/       PyMuPDF の WebAssembly 版
  vendor/fonts/              同梱の日本語フォント（SIL OFL）
tests/                       エンジンのテスト
```

Python のコードは Pyodide（ブラウザ用の Python）の中でそのまま動きます。画面からは `fetch('/api/...')`
で呼んでいるように見えますが、`js/bridge.js` がそれを横取りして、Web Worker の中の Python に渡しています。

**エンジンは別スレッド。** Python と PyMuPDF の読み込みには数十秒、大きなPDFの書き出しには数秒かかります。
これを画面と同じスレッドでやると、その間スクロールも入力も止まります。Worker に置くことで、起動中でも
PDFを開いて読め、50MBのファイルを保存している間も画面は動き続けます。

**編集中の真実はブラウザ側のモデル、保存時に実PDFへ書き込む。** 描画やドラッグでエンジンを呼ばないので操作が軽く、
元に戻す操作も素直に書けます。

**保存は「変わったものだけ」。** 注釈には `/NM`（規格の一意名）で安定したIDを持たせ、前回読み書きした内容と
違うものだけを書き直します。触っていない注釈は1バイトも変わりません。モデルが扱わない種類の注釈（添付ファイル、
フォーム欄、リンクなど）には手を触れません。

**文字の見た目は自前で描く。** PDFエンジン任せにすると、日本語の短い文は「かな＝明朝、漢字＝中国語フォント(Song)」
という指定になり、長い文は別のフォントで描かれ、枠からはみ出た分は黙って切り捨てられます。そこで行の折り返しは
ブラウザが決め（入力中の見た目そのもの）、その位置どおりに、埋め込んだ日本語フォントで外観を書き込みます。
フォントは fontTools で使った文字だけに切り詰めるので、増えるのは数KB〜数十KBです。

**座標系は1つ。** モデルは「見たままの向き」のページ座標（pt・左上原点）。回転ページとの変換は
`py/pdfstudio/common.py` の `to_view` / `to_page` だけが受け持ちます。

**ページを書き換える操作は必ずスナップショットを取る。** だから Ctrl+Z で戻せます。

## テスト

```
python tests/make_sample.py        # テスト用のサンプルPDFを作る（最初に1回）
python tests/test_roundtrip.py     # モデル → 実PDF → モデル の往復
python tests/test_text_fonts.py    # 文字・日本語フォント・画像・差分保存・元に戻す
python tests/test_pages.py         # ページ操作・墨消し・本文編集・余白・分割・OCR結果の埋め込み
python tests/test_rotation.py      # 回転ページでの座標
python tests/test_export.py        # XFDF・CSV・Markdown・一覧PDF
python tests/test_measure_forms.py # 計測・フォーム・文書比較
python tests/test_sign_access.py   # 署名欄・アクセシビリティ
```

必要なのは Python 3.12 と `pip install pymupdf fonttools` だけです（テスト用。アプリを使うだけなら何も要りません）。

画面の操作は、ローカルで配信して実際のブラウザで確かめています（[DEPLOY.md](DEPLOY.md) 参照）。

## 既知の制約

- **電子証明書による署名はできません。** 「署名」は見た目としての署名です。改ざん検知の効力はありません
- **絵文字は保存されません。** 同梱フォントに字形がないためです（画面には出ても、PDFには入りません）
- **太字はゴシックのみ。** ほかの書体は太字の字形を同梱していません。斜体・下線つきの文字はありません
- **本文の編集は行単位**で、書き換えた行は同梱の日本語フォントになります（元のフォントは再現しません）
- **手書きの筆圧は、このアプリの中でだけ線の太さに反映されます。** PDFの手書き注釈は1本の線に太さを1つしか持てないため、他のソフトでは均一な太さになります
- **XFAフォームは非対応**（PDF 2.0 で廃止済み。Acrobat 以外では開けません）
- **編集機能の準備に、初回は30秒〜1分**かかります（PDFエンジン約30MBの読み込み）。その間もPDFを開いて読むことはできます。2回目からは速くなります
- 文字認識（OCR）は初回に言語データ（約20MB）を取得します。縦書きの認識は不得意です
- 上書き保存（元のファイルへ直接）は Chrome / Edge で使えます。ほかのブラウザではダウンロードになります

## 注意 —「見えなくする」≠「消す」

| 罠 | このアプリでの扱い |
|---|---|
| **黒い四角を置いても消えない** | 「墨消し」は指定まで。「墨消しを適用」で初めて実データが消えます |
| **トリミングでは消えない** | 見える範囲を変えるだけです。本当に消すには墨消しを |
| **上書き保存では消えない**（一般のPDFソフト） | このアプリの保存は毎回ファイルを作り直すので、消した内容は残りません |
