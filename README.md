# PDF Studio

ローカルで動く統合PDF編集アプリ。注釈は**規格準拠のPDF注釈**として実ファイルに書き込まれるため、
Acrobat・Edge・Foxit など他のビューアで開いてもそのまま見えて編集できます。

## 現在できること（Phase 0–5・完了）

**表示・移動**
- 複数ページ表示、ページが見えたときだけ描画する遅延レンダリング
- ズーム（50〜400%、幅に合わせる、全体表示）、サムネイル、しおり
- 全文検索（PyMuPDFによるサーバ側検索。行またぎ・傾いた文字にも追従）
- **空白を無視した検索** — 完全一致で見つからないときに自動で切り替わる。OCRした日本語は文字間に空白が入る（「契約 金額」）ため、これが無いと目に見えている語が検索できない

**注釈（すべてPDF規格の注釈として保存）**

| 種別 | 規格サブタイプ | 備考 |
|---|---|---|
| ハイライト／下線／波線／取消線 | `Highlight` `Underline` `Squiggly` `StrikeOut` | 文字を選択して適用。折り返しに沿って複数quadで領域定義 |
| 範囲塗り | `Square` | スキャンPDF・図版用 |
| テキスト／引き出し線 | `FreeText` | 枠線・背景・フォント・引き出し線を1系統に統合 |
| 付箋 | `Text` | アイコン7種 |
| 線・矢印 | `Line` | 先端形状10種を両端に個別指定 |
| 矩形／円／多角形／折れ線 | `Square` `Circle` `Polygon` `PolyLine` | 雲形の枠（強度3段）対応 |
| 手書き | `Ink` | 筆圧・傾き・パームリジェクション対応（下記の制約あり） |
| スタンプ | `Stamp` / `FreeText` | 規格の標準スタンプ14種、またはカスタム文言（動的スタンプ対応） |
| 墨消し指定 | `Redact` | 指定まで（適用はPhase 3） |

**手書きの入力まわり**
- ペンの筆圧を線幅に反映。**マウスでも描画速度から筆圧を擬似生成**するので描き味が揃う
- パームリジェクション（ペンを一度使うと以後は指の接触を無視）
- 二本指スクロール（描画ツール中でもページ送りできる）
- スタイラス専用モード、消しゴム、投げ縄選択

**運用（レビューを回す）**
- Undo/Redo（連続ドラッグは1ステップにまとまる）
- コメント一覧 — 種類・作成者・ステータス・チェック状態で絞り込み、全文検索、5種類の並べ替え、クリックでジャンプ
- **返信スレッド** — 規格の返信注釈（`/IRT` + `/RT /R`）として保存されるので、Acrobat や Foxit のコメントパネルにも同じ会話が出る
- **レビューステータス**（承諾／却下／完了／取り消し）— `/State` + `/StateModel /Review` に書き込まれる
- 絞り込んだ分をまとめて選択して一括で書式・ステータス変更
- 検索して**一括マークアップ**（全ページのヒットに一度で適用）
- 4秒後の自動保存

**出口（注釈を外に出す）**
- **注釈一覧をPDFで書き出す** — ページ順にまとめた別文書。相手がビューアしか持っていなくても読める
- **XFDF** — 注釈だけを軽量ファイルで受け渡し（実測 1.6MB のPDFに対して 2.6KB）。読み込みも可能
- **CSV** — Excel用にBOM付き。マークアップ対象の本文も一緒に出る
- **Markdown** — 色を意味タグ（重要／実行項目／要検討／メモ）として保持したまま知識ベースへ
- **フラット化** — 注釈をページに焼き付ける。実行前に自動でスナップショットを取る
- **注釈の一括削除** — フラット化とは逆の操作。こちらも事前にスナップショット

**文書そのものを変える（層②③・「文書 ▾」メニュー）**

これらはページの中身やファイル構造を書き換えます。**実行前に必ず自動でスナップショット**を取り、`data/work/<id>/snapshots/` に残します。

- ページ操作 — 回転・削除・複製・白紙挿入・別PDFの結合・抽出
- **墨消しの適用** — 指定を実際の削除に変える唯一の操作。検索して一括指定もでき、黒塗りの上に「［非開示］」などの墨消しコードを日本語で載せられる
- **非表示情報の削除** — メタデータ・埋め込みファイル・非表示テキスト・JavaScript・サムネイル
- 透かし／ヘッダー・フッター（`{page}` `{pages}` を展開）／ベイツ番号
- **OCR** — Tesseract 連携。テキストの無いページだけを処理し、認識結果を見えない層として埋め込む。言語とレイアウト解析モードを選べる
- 本文の検索と置換 — 注釈ではなくページの中身を書き換える（元の文字は墨消しで実削除してから置く）
- パスワード保護して書き出し（AES-256・権限個別指定）
- ファイルの最適化（フォントのサブセット化・未使用オブジェクト削除）

**計測・数量拾い（「数量」タブ）**

図面レビュー用の系統。**縮尺の設定が前提**で、未設定のうちはその旨を明示します。

- 縮尺のキャリブレーション — 図面上の既知の寸法をなぞって「これは何メートル」と入力する
- 距離・面積・角度の計測。値はページ上にラベルとして描かれ、実PDFにも残る
- **カウント（数量拾い）** — 分類ごとに独立した連番が自動で振られる
- **分類ごとの自動集計** — 「配管長 1件 17.07m」「コンセント 3件」のように、記録先の名前ごとにまとまる
- CSV書き出し（積算に直結）
- **凡例をページに置く** — 集計表を注釈として配置。移動も印刷もできる

**フォーム（AcroForm）**

- フォーム欄の一覧・入力（日本語のフィールド名と入力値に対応）
- 罫線からフォーム欄を自動作成
- FDF / CSV / JSON での書き出しと読み込み
- **複数の回答PDFを1枚のCSVに集計**
- **XFAフォームは対応しない**と明示（PDF 2.0で廃止済み、Acrobat以外では開けない）。開いた文書がXFAだった場合は、その旨と対処を表示する

**文書を比べる**

- **比較** — ピクセル単位で差分を検出し、**雲形注釈として自動生成**。コメント一覧から1件ずつ確認できる
- **オーバーレイ** — 2つの版を別々の色に変換して透過重ね。ズレと変更が色で浮かび上がる

**署名**

- 手書き風・タイプ・画像の署名を配置。氏名・日時・理由のブロックを添えられる
- 空の署名欄の作成（相手に署名してもらう用）
- 署名の状態確認
- **電子証明書によるデジタル署名は作成できません**と明示。ここで置ける署名は見た目だけのもので、改ざん検知の効力はありません。ダイアログにもその文言を出しています

**アクセシビリティ（目に見えない書き込み）**

- **点検** — タグの有無、言語指定、代替テキストのない画像、テキストのない画像ページ、タイトル未設定を、なぜ問題かと直し方つきで一覧にする
- **自動タグ付け** — 文字サイズから見出しを推定して構造タグを生成し、言語も設定する
- 画像の代替テキスト設定
- **読み上げ順序の可視化** — 支援技術が読む順番を、番号付きの経路としてページ上に描く。段組みが変な順で読まれることに気づけます

**UI**
- **Dynamic Default** — 直前に使った色・太さ・フォントが自動的に次の既定になる
- プロパティパネルは常に1枚。選択がなければ「次に描くときの設定」、選択があれば「その注釈の編集」
- ダークモード／ライトモード
- キーボード: `V`選択 `H`ハイライト `U`下線 `K`取消線 `T`テキスト `N`付箋 `P`ペン `E`消しゴム `L`投げ縄 `I`線 `R`矩形 `C`円 / `Ctrl+S`保存 `Ctrl+Z/Y`取り消し `Ctrl+F`検索 `Del`削除

## 設計上の要点

**編集中の真実はブラウザのJSONモデル、保存時にPyMuPDFが実PDFへ焼き込む。**
描画やドラッグでサーバ往復が起きないので操作が滑らかで、Undo/Redoもコマンドスタックで素直に書ける。
保存時に規格準拠の注釈へ変換し、開くときは既存注釈をJSONへ抽出するので、他社ツールで付けた注釈もそのまま編集できる。

**座標系は1つだけ。** モデルはPDFユーザ空間（pt・左上原点）で、これは
pdf.jsのviewport(scale=1)ともPyMuPDFのページ空間とも一致する。
SVGオーバーレイに `viewBox="0 0 w h"` を与えているので、ズームしても注釈データは不変。

**規格に置き場所がない情報は私用キーに逃がす。**
筆圧プロファイル、レビューのチェック状態、スタンプの文言、FreeTextの枠線色などは
注釈オブジェクトの `/PDFStudio` キーにJSONで持つ。他のビューアは未知のキーを無視するのでファイルの互換性は保たれる。

**保存は常にフルリライト。** 通常のPDF編集ソフトの上書き保存は追記方式（インクリメンタル保存）で、
消したはずのデータがファイルに残る。`Doc.commit()` は毎回ガベージコレクション付きで書き直すため、
削除した内容は実際にファイルから消える。

## 既知の制約

**手書きの筆圧は、このアプリの中でだけ線幅に反映されます。**
PDF規格の `Ink` 注釈は1本のストロークに対して線幅を1つしか持てないため、
他のビューアで開くと**均一な太さ**で表示されます。筆圧のプロファイル自体は私用キーに保存されるので、
このアプリで開き直せば元の強弱がそのまま戻ります。
他のビューアでも強弱を見せたい場合は、Phase 2 で「筆圧を確定して焼き込む」操作を用意する予定です
（焼き込むと以後は線として編集できなくなるため、明示的な操作にします）。

**テキストボックスの枠線は文字色になります。**
PDF規格の `FreeText` 注釈には枠線色を置く場所がなく、ビューアは `/DA` の文字色で枠を描きます。
枠線だけ別の色にはできないため、アプリ側も文字色で枠と引き出し線を描いて表示を一致させています。

**注釈の外観はPyMuPDFが生成します。**
そのため微妙な描画の差（雲形の弧の刻み方など）が、アプリの表示と保存後のPDFで出ることがあります。
位置・色・サイズは一致します。

## テスト

```
python -m tests.test_roundtrip    # モデル→実PDF→モデル の往復検証
python -m tests.test_export       # XFDF・CSV・Markdown・サマリーPDF の検証
python -m tests.test_pages        # ページ操作・墨消し・本文編集・OCR・保護の検証
python -m tests.test_measure_forms  # 計測・数量拾い・フォーム・文書比較の検証
python -m tests.test_sign_access  # 署名・アクセシビリティの検証
python tests\make_sample.py       # 動作確認用のサンプルPDFを生成
python tests\inspect_saved.py     # 直近の保存結果をアプリの外から確認
```

`test_roundtrip.py` が見ているもの:
- 9種類の注釈が実PDF注釈として書き込まれ、再読込で復元されること
- 日本語の作成者名・コメント・本文が保持されること
- 筆圧・矢印形状・雲形・引き出し線・スタンプ文言が往復すること
- 返信スレッドとレビューステータスが規格の返信注釈として往復すること
- **3回保存し直しても図形の座標が動かないこと**（PyMuPDFが枠線分だけ /Rect を膨らませるため、素朴に読み戻すと毎回大きくなる）
- **墨消しを適用したら本文から実際に文字が消えること**
- XFDFがPDF本体よりはるかに小さく、書き出して読み戻しても座標とステータスが保たれること
- サマリーPDFのフォントがサブセット化されていること（しないと数MBになる）

`test_pages.py` が見ているもの — ここは**「隠す」と「消す」の違い**を証明する場所:
- **トリミングは消去ではない**こと（枠を戻すと本文が復活することを、あえて確認している）
- 墨消しは**指定しただけでは本文が残り、適用して初めて消える**こと。保存し直しても復活しないこと
- 墨消しコード（日本語）が黒塗りの上に描かれること（既定のHelveticaでは無言で消える）
- 本文置換で元の文字が残らないこと
- OCRが日本語と数字を認識し、**空白無視検索で見つけられる**こと
- パスワード保護で、権限（コピー禁止など）が実際に効いていること

`test_measure_forms.py` が見ているもの:
- 縮尺 200pt = 10m のとき、400pt の線が 20m、200×200pt の四角が 100m² になること
- 角度は度で表され、合計しないこと（角度の総和に意味はない）
- 日本語のフィールド名と入力値が、保存し直しても残ること
- 作ったフォームがAcroFormであること（XFAではない）
- 同一文書では差分が0件、変更した箇所だけが雲形注釈になること

`test_sign_access.py` が見ているもの:
- 手書き署名がInk注釈として、タイプ署名の日本語がページに入ること
- **電子証明書による署名は作れないと報告すること**（できないことを、できないと言う）
- タグの無い文書をタグ無しと判定し、なぜ問題かと直し方を返すこと
- 自動タグ付けの後に、タグと言語の指摘が実際に消えること
- 代替テキスト（日本語）が保存され、入れると指摘が消えること

保存したPDFは **Microsoft Edge のPDFビューア** でも開いて確認してください。
そこで正しく見えることが「他のツールでも見える」の実証になります。

## 注意 —「見えなくする」≠「消す」

元資料が最重要と位置づけている落とし穴です。このアプリでの扱いは次のとおり:

| 罠 | このアプリでの扱い |
|---|---|
| **注釈の黒塗りでは消えない** | 墨消しツールは「指定」までで、メニューの「墨消しを適用」を実行して初めて実データが消えます。適用ダイアログにその旨を明記しています |
| **トリミングでは消えない** | CropBox を変えるだけで枠外のデータは残ります。本当に消すには墨消しを使ってください |
| **上書き保存では消えない** | このアプリの保存は**毎回フルリライト**（ガベージコレクション付き）なので、この罠は構造的に踏みません |

墨消しを適用したあとは、「非表示情報を削除」も併せて実行すると、メタデータや埋め込みファイルに残る痕跡まで取り除けます。
